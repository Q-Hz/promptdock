## 实现

- `src-tauri/src/import_logic.rs`：`use_imported` 在同一事务中更新全部 10 个字段，包括 `id`、`useCount`、`lastUsedAt`、`createdAt`、`updatedAt`。使用普通 UPDATE，不使用 OR REPLACE；保留已有候选快照重验、重复导入 ID 拒绝、重复更新目标拒绝和全量回滚保护。
- `src/lib/import-selection.ts`、`ManagerApp.vue`：提交成功后将当前选中本地 ID 映射到对应导入 ID，再刷新编辑区，避免替换后丢失选中项。
- `ImportComparePage.vue`、`ResizableSplit.vue`、`src/lib/split-pane.ts`：三级分区允许调整列表宽度、基本信息高度、正文/操作区比例；正文填充剩余空间；卡片内容独立滚动，底部操作按钮固定可见。窗口缩小时限制最小区域，极小空间按比例收缩。
- 分隔条支持指针拖动、方向键（16px）、Shift + 方向键（40px）、Home/End 到边界、双击或 Enter 恢复默认值；提供可聚焦 separator 语义。ResizeObserver 在卸载时断开。
- `src/lib/i18n.ts`：中英文同步调整两项说明，补充分隔条名称。英文较长说明使用更高的初始选项区；深色模式下分区内原生控件和滚动条采用深色方案。
- 无数据库 schema、导入 JSON 格式或 Tauri 命令签名变更。自动跳过规则仍只比较业务内容；仅使用记录不同的条目仍按原规则自动跳过。
