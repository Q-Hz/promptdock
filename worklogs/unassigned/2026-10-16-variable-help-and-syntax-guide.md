## 摘要

将变量示例整理为“需求、正文写法、调用效果”三部分，并补充真实控件截图和生成后的文字，帮助用户选择合适语法。将内置中英文提示词标准化模板更新为可先发给 AI 学习、再继续编写模板的语法指南。另提供可直接复制的功能验收 Prompt 和逐步预期结果。

## 修改范围与决定

- `src/components/VariableExamplesModal.vue`、`src/lib/i18n.ts`、`src/lib/variable-examples.ts`：五类语法均给出具体需求、可用源文、生成示例和调用截图。宽窗口三栏对照，窄于 1024px 时顺序堆叠；正文独立滚动，关闭按钮保持可见，键盘焦点留在弹窗内。
- `src/assets/variable-examples/{zh,en}/`：10 张图片，均通过后台浏览器截取真实 `LauncherApp.vue` 控件；截图内容来自同一份本地化示例，没有用户数据。普通填写、默认值、单选、多选、展开片段和内部字段均有图示。
- `src-tauri/src/default-prompts.json`：仅修改“提示词标准化”和“Prompt Standardization”的正文；12 条模板的 ID、分类、状态及其他记录完全保留。
- `examples/promptdock-syntax-guide.{zh,en}.md`：与两条内置正文完全相同，可用于更新已有安装中的旧模板。涵盖五类语法、默认与顺序、共享变量、条件字段、校验和编写步骤。
- 教学指南使用单层大括号及带 `>` 的教学示例，明确要求 AI 输出实际模板时改为双层 ASCII 大括号并去掉引用前缀。这保证指南本身在 PromptDock 中调用时不会被替换变量或移除定义；未修改模板解析或增加转义语法。
- `examples/optional-snippets-test.txt` 与 `examples/README.md`：可直接复制到正文的测试模板，以及默认顺序、重选顺序、暂存、重复引用、共享语言、单段开关、空选择和冲突的人工检查步骤。
- 中英文 README 更新了语法指南的新使用流程与示例入口。
- `tests/prompt-guides.test.ts`、相关浏览器脚本和 `tests/browser/launcher-preview.ts`：校验交付文本的实际可用性，提供截图复现入口。`package.json` 纳入新增测试。
