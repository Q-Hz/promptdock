## 实施区域与决策

- `src/lib/folder-icons.json`、`folder-appearance.ts` 和 `manager/FolderIcon.vue`：40 个本地线条 SVG；文件夹、书本、包裹、三角、箭头随折叠状态切换，其余单形态。默认中性色跟随深浅主题，其余七色固定。图标路径在项目内绘制，不引入第三方图标包、字体或运行时网络请求。
- `manager/FolderIconPicker.vue`、`FolderSection.vue`、`ManagerApp.vue`、`i18n.ts`：全分区右键更改，预览两状态，完成/取消/恢复默认，保存失败保持面板及原图标。面板打开时背景 inert，阻止后台快捷键及 JSON 拖入，支持焦点循环和 Escape。标题及分批操作按确认方案调整，既有长按拖拽保留。
- `src-tauri/src/folder_appearance.rs`、`main.rs`、`import_logic.rs`、`src/lib/api.ts`：新增 `folder_appearance(name, icon, color)` 表，升级时创建，旧数据按默认展示。新增 `set_folder_appearance` 命令；库快照和文件夹 CRUD 返回图标元数据。重命名/删除与提示词、排序在同一事务中迁移/清理。
- JSON 顶层 `folderAppearance` 为以分区键索引的 `{icon,color}` 映射，普通文件夹以名称为键，未分类为空字符串，置顶为已有保留键 `\u0000pinned`。不存在的普通文件夹键被忽略，未知图标/颜色分别回退默认，不创建幽灵文件夹。新旧文件合并规则按确认方案处理，覆盖导入也保留旧文件的同名本地图标、清理消失文件夹的图标。图标随导入预检查快照传递，stale 后重新检查不丢失元数据。
- 新增前端图标测试、浏览器图标检查、Rust 元数据/CRUD/导入回归；同步既有浏览器测试的文案、菜单和左对齐预期。`npm test` 已包含新测试，另提供 `npm run test:folder-icons`。
