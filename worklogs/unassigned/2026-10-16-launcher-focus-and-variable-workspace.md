## 摘要与确认范围

修复开发模式下变量页、生成结果页点击外部后意外隐藏的问题；管理器正文增加浅色语法高亮，整理可选片段组的层级，并为变量填写页增加实时生成结果预览。用户明确确认使用实时替换后的完整结果，宽窗口左右排列、窄窗口上下排列，可收起；问题发生于 `npm run tauri dev` 开发版。浏览器沿用用户已选择的后台模式。

## 修改区域与实现决策

- `src/components/LauncherApp.vue`：原有失焦处理已限制在搜索阶段，但异步 `onMounted` 在组件卸载后可能继续注册旧实例的 `blur` 监听。开发热更新时，旧实例仍处在搜索阶段，会隐藏正在填写的新实例。将 DOM 监听注册移到同步挂载阶段，增加卸载状态检查；晚到的 Tauri 事件订阅立即退订。保留搜索页失焦隐藏、Esc 逐级返回、返回修改确认及复制成功关闭行为。
- `src/components/PromptBodyEditor.vue`、`src/lib/template-highlight.ts`、`ManagerApp.vue`：保留原生 textarea 的编辑、选择、撤销与输入法机制，背衬层分别突出普通变量、片段引用和定义标记。两层使用同样的字体、换行、制表与宽度，滚动同步；中文组合输入期间使用原生文字层，系统高对比度模式回退原生文字。用户内容通过 Vue 文本插值展示，不作为 HTML 执行。高亮仅负责显示，不参与模板解析或校验。
- 可选片段以组边界和标题区分，显示已选数量；勾选项使用柔和底色，展开按钮弱化，内部变量缩进并用细线表明归属。收起全文仍显示填写框，缓存、排序与共享字段规则不变。
- 变量预览复用 `SnippetSession.render()` 与现有安全 Markdown 渲染器，不更新生成结果编辑基线或变量值。错误模板显示修正提示；空结果显示空状态。预览沿用全局预览开关及持久化，变量页开启时复用原生窗口扩宽接口。窄窗口上下排列，极短窗口让表单和预览共同滚动，操作按钮始终固定。
- `src/lib/i18n.ts`、中英文 README：补齐中英文预览、片段数量文案及操作说明。
- `tests/browser/launcher-preview.ts`：合成 IPC 增加延迟设置读取和组件重挂载，复现热更新生命周期问题；不访问实际数据库。
