# 语法指南与可导入的验收 Prompt

## 让 AI 学会 PromptDock 语法

- [中文语法指南](promptdock-syntax-guide.zh.md)
- [English syntax guide](promptdock-syntax-guide.en.md)

两份指南已同步至安装时初始化的“提示词标准化”与“Prompt Standardization”默认提示词。调用时可填写原始提示词、选择输出语言并补充备注，生成后将完整内容发送给 AI。

- 填写原始提示词：AI 按语法指南、输出语言和备注直接改写为可复用模板。
- 原始提示词留空：AI 仅确认已理解指南，等待后续任务。

教学示例使用单大括号及引用前缀，AI 输出实际模板时需改为双大括号并移除前缀。只有文末的原始提示词、输出语言和备注是本次调用的真实填写项。已有库中的已保存正文不会被默认数据更新自动覆盖。

## 测试可选片段功能

在软件管理器中导入 [测试 JSON](optional-snippets-test.json)，选择追加导入。文件包含一条“可选片段功能验收”Prompt，导入后在“功能测试”文件夹中调用，无需手动新建或粘贴正文。

| 操作 | 应看到的结果 |
| --- | --- |
| 第一次调用 | 普通填写框、默认任务名称、语言单选、检查范围多选；“附加修复”默认勾选“修复公式标题”和“清理公式空行”。 |
| 查看两个组 | “附加修复”只显示一组控件，尽管正文引用了两次；“输出说明”只有一项，作为开关。 |
| 展开“修复行内符号”，暂不勾选 | 可以读全文，但没有“符号”填写框。 |
| 勾选“修复行内符号” | 下面出现“符号”，默认是 `u`；插入顺序为“修复公式标题 → 清理公式空行 → 修复行内符号”。 |
| 填 `u_0`，收起全文 | 填写框和 `u_0` 仍显示。 |
| 取消后重新勾选“修复行内符号” | 填写框恢复 `u_0`。 |
| 取消“修复公式标题”后重新勾选 | 插入顺序变为“清理公式空行 → 修复行内符号 → 修复公式标题”。 |
| 勾选“附上修改说明” | 出现“说明重点”填写框；“语言”仍只填一次，使用上方的语言选择。 |
| 填写笔记内容、勾选检查范围，再生成 | 所有变量被替换；两处“附加修复”输出相同内容、顺序相同。没有定义标记或未选片段，片段内部空行与缩进保留。 |
| 所有组都不选，再生成 | 不出现片段文字，独占一行的引用连同该行移除；模板中的固定标题仍保留。 |
| 返回搜索，再次调用这条 Prompt | 回到模板默认勾选与默认填写值，不延续上次缓存。若返回时有有效改动，按提示放弃即可。 |

可填入下面这段无敏感信息的测试笔记；无需发给 AI，也能在生成后的原文中检查模板功能：

```text
# 测试笔记
正文变量 (u) 需要检查。

公式块中的标题标记与空行需要检查。

- 第一项

- 第二项
```

额外检查冲突时，可临时将“输出说明”片段里的语言定义改成 `{{语言=[English|中文]}}`。管理器应显示潜在冲突及行号；仅在勾选该片段后，调用界面才阻止生成。测试完恢复原定义。
